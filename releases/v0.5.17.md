# Side A 0.5.17

- Always-current limits: when an account's login goes idle, Side A renews it the same way Claude Code does, then reads it right away. No message is sent, no quota is used, and it works at any hour.
- Heads-up before a sign-in ends: each Claude sign-in lasts about a month. Side A tells you three days ahead so no account drops out.
- No more false "Couldn't connect": when the usage service asks Side A to slow down, the last reading stays, with its time once it ages. The account in use is read every three minutes.

macOS 14 or later. Apple Silicon and Intel. Free.
